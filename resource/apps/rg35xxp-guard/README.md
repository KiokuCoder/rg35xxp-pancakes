1. 这个程序会接受命令，并且运行子程序
2. 子程序的输入输出会继承当前程序
3. 启动之后会监听电源键，如果电源键按下会开启、关闭屏幕。并且恢复、暂停子程序
4. 启动之后会监听音量键，调节系统音量
5. 子程序退出之后，这个程序会返回子程序退出代码

## 音量键

音量键调的是 alsa 的 `digital volume`（`amixer cset name="digital volume" N`，0-63），
和 rg35xxp-launcher 设置页里那个是同一个控件，也同样按 10% 一档走，两边调出来的值能对上。
改的是系统音量，退出子程序之后仍然保留。

音量键不一定和电源键在同一个输入设备上，所以按 `KEY_VOLUMEUP`/`KEY_VOLUMEDOWN` 另找了一遍
设备。两种键都不 grab，事件照样会传给子程序（目前没有子程序用到它们）。找不到音量键设备、
或者系统里没有 `amixer`/没有这个控件，都只打一条日志，不影响子程序启动。

所有走 `rg35xxp-guard <cmd>` 启动的程序（vmrp / RetroArch / ppsspp / mpv 等）都能用音量键。
